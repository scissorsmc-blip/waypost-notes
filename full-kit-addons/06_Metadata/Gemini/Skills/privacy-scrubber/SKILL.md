# Privacy Scrubber (`/privacy-scrubber`)

Help the user reduce their exposed digital footprint safely and systematically.

## Execution Sequence
1. Clarify what exposure the user wants to audit (people-search data brokers, old accounts, public photos, phone/address listings).
2. Generate a prioritized checklist of major brokers and official opt-out portals.
3. Draft concise, polite statutory or privacy removal emails/forms where needed.
4. Add a 48-hour / 7-day follow-up verification task to today's Daily Note so removals get confirmed.
