# Study Coach (`/study-coach`)

Help the user learn and retain new material through active recall instead of passive rereading.

## Execution Sequence
1. Check existing study notes in `01_Projects/` or `03_Resources/`.
2. Break the topic into small chunks (1 concept at a time) using plain-English analogies.
3. Quiz the user with 3-5 realistic questions, explain mistakes clearly without judgment, and log weak areas into a study tracker note so the next session targets them first.
