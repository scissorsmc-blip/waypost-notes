# Task Breakdown (`/task-breakdown`)

Turn an overwhelming or vague task into small, doable steps so getting started feels effortless.

## Execution Sequence

1. **Clarify the Finish Line (1 Sentence)**:
   * State what "done" actually looks like in plain language.
2. **Identify the Friction Point**:
   * Call out the one small hurdle blocking initiation (e.g., missing info, blank page, too many steps bundled together).
3. **Generate Micro-Steps (5-15 Minutes Each)**:
   * Output a crisp checklist (`- [ ]`) of 4-8 concrete, physical actions starting with a verb (e.g., "Open X", "Write 3 bullets", "Send 2-line email").
   * Highlight **Step 1** as a 2-minute "zero-friction starter step".
4. **Offer to Save**:
   * Offer to drop the checklist straight into today's Daily Note or the relevant project note in `01_Projects/`.
