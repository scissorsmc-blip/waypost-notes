# Waypost Notes: Beginner's Start-to-Finish Guide

Welcome. Waypost Notes is a calm, local-first personal workspace built on **Obsidian**, **Granola** meeting notes, and persistent AI memory. You do **not** need a technical background. Take it one step at a time and take breaks whenever you need them.

> **Volunteer-Run Project:** Waypost Notes is built and maintained solely by volunteers in their spare time.

## Step 1: Pick Your Edition Guide

Both editions give you the exact same calm dark theme, PARA folders, free Granola meeting sync, and 24 modular skills. Pick the guide that matches how you want to work:

### 1. Copilot Edition *(Recommended for Beginners & Mobile)*
* Everything runs inside **one single app: Obsidian** using the [Obsidian Copilot plugin](https://github.com/logancyang/obsidian-copilot).
* Pre-configured for free Google Gemini, and works with **any Copilot-compatible AI** (OpenAI, Claude, Groq, OpenRouter, or local offline Ollama).
* **Open the full step-by-step checklist:** **[Copilot Edition Beginner Guide](editions/copilot/BEGINNER_GUIDE.md)**

### 2. Antigravity Edition *(Desktop Power Workspace)*
* Pairs **Obsidian** (zero plugins required) with the official **Google Antigravity** desktop app and CLI.
* Uses simple Google account sign-in with no API key setup.
* **Open the full step-by-step checklist:** **[Antigravity Edition Beginner Guide](editions/antigravity/BEGINNER_GUIDE.md)**

## Quick One-Command Installers

If you already know which edition you want, copy one command below (or run the interactive installer to choose on screen):

* **Copilot Edition (Windows PowerShell):**
  ```powershell
  irm https://raw.githubusercontent.com/scissorsmc-blip/waypost-notes/main/installers/install-copilot-windows.ps1 | iex
  ```
* **Copilot Edition (macOS Terminal):**
