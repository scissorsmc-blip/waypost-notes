# Open-Source Pipeline (`/oss-pipeline`)

Identify reliable, actively maintained open-source or local-first alternatives to paid software subscriptions.

## Output Format
1. **Top 2-3 Alternatives**: Compare maturity, ease of setup for non-technical users, platform support (Windows/Mac/Mobile), and true cost.
2. **Migration Trade-Offs**: Call out honestly what features are better, what is missing, and how data exports cleanly.
3. **Recommended Pick**: Clear verdict tailored to the user's comfort level.
