# Waypost Notes AI Memory Cockpit

> **Status**: Vault-Native AI Memory Active (**Obsidian Copilot + Google Gemini**)
> **How This Works**: Every memory note, custom prompt, system prompt, skill, plan, summary, and saved chat lives inside `06_Metadata/Gemini/`. Because everything is stored as plain Markdown inside your Obsidian vault, your AI memory stays private, transparent, and synced across desktop, tablet, and phone.

---

## Memory Directory Map

| Folder | Purpose |
| :--- | :--- |
| **`06_Metadata/Gemini/Memory/`** | Long-term facts and preferences remembered by Obsidian Copilot. |
| **`06_Metadata/Gemini/Prompts/`** | Slash-command workflows triggered by typing `/` in Copilot chat. |
| **`06_Metadata/Gemini/System-Prompts/`** | Persistent system rules (`Waypost Operating Rules.md`). |
| **`06_Metadata/Gemini/Skills/`** | Modular agent skills (`SKILL.md`) used by Copilot Agent Mode. |
| **`06_Metadata/Gemini/Plans/`** | Project plans, blueprints, and step-by-step designs. |
| **`06_Metadata/Gemini/Walkthroughs/`** | Summaries of completed milestones. |
| **`06_Metadata/Gemini/Artifacts/`** | Research reports, outlines, and reference docs. |
| **`06_Metadata/Gemini/Agent-Sessions/`** | Auto-saved Copilot conversations (`autosaveChat: true`). |
| **`06_Metadata/Gemini/Backups/`** | Pre-edit file snapshots for safe undo. |
